CRISP-DM Workflow & Model Details

Transparent reproducible process — actual sklearn estimates, not placeholder charts
1. Business UnderstandingPredict startup profit from spending and state. Determine whether smaller feature sets generalize as well as more complex models.
2. Data Understanding50 rows; predictors: R&D, Administration, Marketing, State. Target: Profit (same currency units as original dataset).
3. Data PreparationOne-hot encode State with California dropped. Fixed 40/10 train/test split (random_state = 0). StandardScaler is fitted inside each training fold, preventing scaler leakage.
4. ModelingFive feature selectors: Lasso and ElasticNet coefficient ranking after fitting the full training data, backward RFE using OLS, forward greedy SFS, and exhaustive best subset search. Each selector produces nested subsets of size 1–5 except exhaustive search, which independently picks the best subset at each size. Five regressors: OLS, Ridge α=1, Lasso α=100, ElasticNet α=0.1, L1 ratio=0.5, BayesianRidge.
5. EvaluationFor forward and exhaustive selection, subsets are selected using 5-fold CV RMSE on training data (KFold shuffle=True, random_state=42), or optionally using the test set in demo mode. Other selector rankings are fitted on training data only. Each subset is then evaluated on the same held-out test records. Adjusted R² uses test-set n=10, so it is unstable; F-statistic/p-value are computed on the 40-row OLS-style training fit and should be treated cautiously for penalized models.
6. DeploymentThis self-contained dashboard contains precomputed, reproducible results for all 31 non-empty feature subsets and five estimators. Interface interactions instantly select from those actual computed predictions and scores. To analyze a different dataset or change hyperparameters, regenerate the data bundle with the included Python build script.

Important: selecting features with the held-out test metric introduces selection bias. Use training cross-validation for a defensible report. The data is too small to draw strong conclusions from one train/test split.
